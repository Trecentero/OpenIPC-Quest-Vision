# OpenIPC Quest Vision

Stream any OpenIPC camera directly to Meta Quest 3 using Quest WiFi.
No cables, no capture card, no PC.

## Goal
Use cheap OpenIPC cameras as wireless eyes for animal vision experiments:
- Head-tracked wireless camera
- IR night vision with OpenIPC IR cameras
- Multi-camera vision (front + back)

## Hardware
- Meta Quest 3
- OpenIPC compatible camera (ex: cheap IP camera flashed with OpenIPC)
- Same WiFi network
